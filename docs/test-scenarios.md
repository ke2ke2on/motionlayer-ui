# MotionLayer 화면 점검표

폰·PC·TV 화면을 처음부터 끝까지 눌러 보며 이상한 곳을 찾는 표예요. 한 줄씩 해 보고 `[ ]`를 `[x]`로 바꾸세요. 이상하면 `[!]`로 바꾸고 맨 아래 "버그 적는 법"대로 적어요.
순서: 폰은 1번(첫 실행 안내)부터 9번까지, PC는 10번, TV는 11번이에요. 괄호 안의 번호(ON-01 등)는 Figma 화면 번호예요.

## 0. 시작하기 전에

**폰(갤럭시)에 앱 올리기**
1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호**를 7번 눌러 개발자 모드를 켠다
2. 설정 → 개발자 옵션 → **USB 디버깅**을 켠다
3. USB로 컴퓨터에 연결하고, 폰에 뜨는 "USB 디버깅을 허용할까요?"에서 허용한다
4. Android Studio 위쪽 기기 칸에서 폰을 고르고 ▶를 누른다

**알아 둘 것 (버그가 아니에요)**
- 모든 데이터는 **가짜**예요(재생 중인 앱, 통계, PC, 앱 목록, 기기, 연습 결과). 센서·QR 카메라·진동·시스템 알림·안드로이드 허용 창은 아직 연결 전이에요. 확인할 것은 **화면 모양, 글자, 터치, 스크롤, 화면 이동**이에요.
- 앱을 **완전히 끄면**(최근 앱 화면에서 밀어서 종료) 설정·권한·로그인·앱 켜짐이 처음 값으로 돌아가고, 켤 때마다 첫 실행 안내가 먼저 나와요.
- 가짜 권한은 요청하면 곧 허용되고, "설정 열기"는 허용 ↔ 허용 안 됨을 뒤집는 것으로 흉내 내요.
- 앱 목록에서 앱을 꺼도 홈에는 YouTube Music이 계속 "지금 조작하는 앱"으로 나와요.

**시연용 동작** (디버그 빌드에서만. 아래 자리를 **길게 누르면** 목록이 열려요)
- 홈 맨 위 **"MotionLayer"**: 토스트 6가지, 인터넷 끊기·다시 연결, 상태 확인 중·감지 멈춤·걷는 중, 앱·제스처 목록 불러오는 중, 동기화 대기, PC 응답 없게, 최근 PC 비우기
- 첫 실행 안내: ON-01 **앱 아이콘**(안내 건너뛰고 홈으로), ON-02 **회색 원**(오른쪽 휙 인식), ON-10 **회색 카드**(다음 로그인 실패)
- 연습 모드 **궤적 카드**: 성공 +1 등
- 제스처 만들기 화면 **큰 제목**: 동작 녹화, 동작이 달라요, 겹침, 확인 인식됨·안 됨
- 발표 중 **"남은 시간"** 줄: 다음·이전 슬라이드, 되돌림, 5분 남음, 연결 끊김, 누른 채 두 번 톡톡
- 기기 목록 제목 **"기기"**: 다음에 찍는 기기 바꾸기

## 1. 첫 실행 안내 (ON-01~11)

- [ ] 1-1 앱을 켜면 환영(ON-01): 파란 앱 아이콘, "폰을 움직여서 조작해 보세요", 설명 두 줄, "시작하기", 그 아래 작은 회색 "로그인은 나중에 해도 돼요"
- [ ] 1-2 "시작하기" → 체험(ON-02): "건너뛰기", "체험해 보기", 회색 원 안의 폰과 파란 화살표, "● 움직임을 기다리고 있어요", "인식되면 짧게 한 번 진동해요"
- [ ] 1-3 회색 원 길게 눌러 "오른쪽 휙 인식시키기" → 성공(ON-03): 초록 체크, "잘했어요! 방금 그게 전부예요", 진동 안내 세 줄(파랑·초록·빨강 아이콘), "다음"
- [ ] 1-4 ON-02에서 "건너뛰기" → ON-03 없이 기본 제스처(ON-04). 거기서 뒤로 가면 ON-01이다
- [ ] 1-5 ON-04: "네 가지만 기억하면 돼요", 제스처 네 줄(좌우로 휙·두 번 톡톡·기울여 유지·세게 흔들기)과 설명, 회색 안내, "다음"
- [ ] 1-6 "다음" → 알림 안내(ON-05) → "알림 허용하기" 또는 "나중에 할게요" → 배터리 안내(ON-07) → "설정 열기" 또는 "나중에 할게요" → 앱 고르기(ON-08)
- [ ] 1-7 ON-08: "어디에서 쓸까요?", 앱 줄과 토글(YouTube Music·멜론 켜짐), 맨 아래 "전화" 줄, 큰 버튼 "2개 앱에서 사용하기". 토글을 바꾸면 숫자가 바뀌고(전화는 세지 않음), 모두 끄면 "나중에 고를게요"가 된다. 마지막 줄이 버튼에 가리지 않는다
- [ ] 1-8 버튼 → 알림 접근 안내(ON-09) → "설정에서 허용하기" 또는 "나중에 할게요" → 로그인(ON-10): 폰·노트북·TV 그림, "PC·TV도 쓰려면 로그인해 주세요", "G Google로 계속하기", "건너뛰기"
- [ ] 1-9 "Google로 계속하기" → "로그인하는 중…"(눌리지 않음) → 준비 완료(ON-11). "건너뛰기"도 ON-11로 간다
- [ ] 1-10 ON-10 회색 카드 길게 눌러 "다음 시도 실패시키기" 뒤 로그인 → 빨간 "로그인하지 못했어요. 인터넷을 확인하고 다시 눌러 주세요." 다시 누르면 넘어간다
- [ ] 1-11 ON-10에서 뒤로 가면 ON-08이다(ON-09는 건너뜀). ON-05·07에서 뒤로 가면 바로 앞 안내다
- [ ] 1-12 ON-11: 파란 체크, "준비됐어요", 켠 앱 이름이 든 문장("YouTube Music이나 멜론에서 노래를 틀고…"; 하나면 그 앱만, 없으면 "'앱' 탭에서 쓸 앱을 고르고…"), 안내 세 줄, "홈으로"
- [ ] 1-13 "홈으로" → 홈(감지 켜짐). 앱 탭의 "사용 중"이 ON-08에서 고른 것과 같다. 홈에서 뒤로 가면 앱이 끝난다(안내로 돌아가지 않는다)

## 2. 홈 (HM-01~08)

- [ ] 2-1 처음: "켜져 있어요", 지금 조작하는 앱 YouTube Music과 칩, "PC 연결 안 됨", 오늘 인식 23회·되돌림 1회, "제스처가 잘 안 되나요?" 카드
- [ ] 2-2 감지 카드의 글자 줄이나 스위치를 누르면 "꺼져 있어요" / "제스처에 반응하지 않아요"가 되고 조작 카드도 꺼짐 모양이 된다
- [ ] 2-3 (앱을 완전히 끄고 안내를 건너뛴 뒤) 감지를 껐다 켜면 ON-05 → ON-09 → 홈(켜짐). 다시 껐다 켜면 안내 없이 바로 켜진다
- [ ] 2-4 안내에서 "나중에 할게요"를 눌러도 켜진다. ON-05·ON-09에서 뒤로 가면 홈이고 감지는 꺼진 채다
- [ ] 2-5 톱니 → 설정, "기록 보기" → 기록, 연습 카드 → 연습 모드, PC "연결" → QR 화면. 모두 뒤로 가면 홈이다
- [ ] 2-6 조작 카드 → 시트(HM-06) "어디를 조작할까요?": "이 폰"(선택됨), PC 줄(흐리게 "연결 안 됨", 눌리지 않음), "폰을 기기 쪽으로 향해서 고르기". 감지가 꺼져 있으면 시트 대신 앱 탭이 열린다
- [ ] 2-7 시트는 "이 폰" 다시 누르기, 어두운 곳 누르기, 아래로 밀기, 뒤로 가기로 닫힌다
- [ ] 2-8 PC를 연결하면 조작 카드가 "지금 조작하는 기기 · 강의실 PC"와 PC 칩으로 바뀐다(토스트 없음). 시트에서 "이 폰" → "이제 이 폰을 조작해요 [되돌리기]" → "되돌리기"를 누르면 PC로 돌아온다. PC "끊기" → 앱 기준으로 돌아온다
- [ ] 2-9 시연 "상태 확인 중 2초": 카드 자리에 깜빡이는 회색 막대와 "감지 상태를 확인하고 있어요", 2초 뒤 원래 홈
- [ ] 2-10 시연 "감지 서비스 멈춤": 주황 경고 배너, "멈췄어요" 카드(빨간 점, "다시 켜기"), "멈춰 있어요" 카드, PC 카드. "다시 켜기" → 권한이 있으면 정상 홈, 없으면 ON-05
- [ ] 2-11 시연 "걷는 중": 파란 안내, 감지 카드 주황 점 "걷는 중 · 주머니 두드림만 받아요", 조작 카드 "재생 중"과 칩 둘. 감지를 끄면 걷는 중 표시가 사라진다
- [ ] 2-12 시연 "인터넷 끊기": 맨 위 안내 배너, PC 카드 "강의실 PC / 같은 와이파이 · 인터넷 없이 연결 가능"(연결 눌림). "다시 연결" → 원래대로

## 3. 앱 탭 (AP-01~08)

- [ ] 3-1 앱을 켠 뒤 처음 열면 권한 안내(AP-05): 회색 아이콘, 설명, "권한 설정으로 이동" → 목록. 다른 탭에 갔다 와도 목록이다
- [ ] 3-2 목록: 제목, 검색창, "사용 중 2"(YouTube Music·멜론), "전화" 구역, "설치된 앱 11"
- [ ] 3-3 토글을 켜고 끄면 앱 줄이 두 구역 사이를 옮겨 가고 숫자와 설명("기본 동작"/"음악"·"동영상")이 바뀐다
- [ ] 3-4 검색: `y`, 한글("멜") 모두 걸러진다. 검색하는 동안 전화 구역이 숨는다. 검색 키를 누르면 키보드가 내려가고, 키보드가 올라와 있을 때 하단 탭이 숨는다
- [ ] 3-5 없는 이름(zzz) → 돋보기 그림, "일치하는 앱이 없어요", 설명, "검색어 지우기"(누르면 전체 목록)
- [ ] 3-6 시연 "앱 목록 불러오는 중": "설치된 앱을 불러오는 중이에요"와 회색 줄 여섯 개, 2초 뒤 목록
- [ ] 3-7 맨 아래 줄이 하단 탭에 가리지 않고, 다른 탭에 갔다 와도 스크롤 위치가 남는다
- [ ] 3-8 앱 줄(토글 말고) → 앱 설정(AP-02): 큰 아이콘, 이름, "이 앱에서 제스처 사용", 제스처 5줄과 나만의 제스처 줄("원 그리기 · 다음 곡"), "기본값으로 되돌리기". 동영상 앱의 휙은 "10초 앞으로·뒤로"다
- [ ] 3-9 줄 → 시트(AP-03): 지금 값에 체크, 맨 아래 "사용 안 함", "저장". 저장하면 바뀌고, 저장 없이 닫으면 그대로다
- [ ] 3-10 "오른쪽 휙"을 바꾸면 홈의 첫 칩이 따라 바뀐다. "이 앱에서 제스처 사용"을 끄면 목록에서 "설치된 앱"으로 내려간다
- [ ] 3-11 "원 그리기" 동작을 바꾸면 제스처 탭의 줄 설명이 따라 바뀌고, "사용 안 함"이면 "쓰는 앱이 없어요"가 된다
- [ ] 3-12 "기본값으로 되돌리기" → 기본 5줄은 기본 동작, 나만의 제스처 줄은 "사용 안 함"
- [ ] 3-13 "전화" 줄 → 전화 제어(AP-04): 스위치("켜면 전화 권한을 물어봐요"), "전화가 올 때" 3줄, "통화 중" 1줄(화살표 없음), 안내 배너. 켜면 "전화 권한 허용됨", 목록의 전화 토글도 같이 켜진다
- [ ] 3-14 설정 → 권한에서 "전화"를 "허용 안 됨"으로 바꾸면 전화 토글이 꺼진다

## 4. 제스처 탭 (GS-01~17)

- [ ] 4-1 목록: 연습 카드("4가지 중 N가지를 익혔어요"), 기본 제스처 4줄(성공률), "나만의 제스처"와 "+ 만들기", "원 그리기" 줄
- [ ] 4-2 시연 "제스처 목록 불러오는 중": "최근 7일 인식률을 계산하는 중이에요"와 회색 자리, 2초 뒤 목록
- [ ] 4-3 연습 카드 → 연습(GS-09): 칩 4개, 안내, 궤적 카드, 점. 칩을 바꾸면 안내와 점이 바뀐다. 궤적 카드 길게 눌러 성공을 채우면 점이 찬다
- [ ] 4-4 네 가지를 모두 3번씩 채우면 완료(GS-10) → "홈으로". 연습에서 뒤로 가면 제스처 탭이다
- [ ] 4-5 기본 제스처 줄 → 상세(GS-02): 이름, 설명, 그림, 인식률·되돌림 카드, 감도 슬라이더, "연습하기". 네 가지 모두 내용이 다르다. "세게 흔들기"는 "0.6초 안에 세 번…10초 안에만 되돌려요", "되돌린 횟수 4회"다
- [ ] 4-6 감도는 나갔다 와도 남는다. "연습하기" → 그 제스처가 골라진 연습 모드
- [ ] 4-7 "+ 만들기" → 이름(GS-03): X, "1 / 3", 입력 칸(키보드가 올라옴). 비어 있으면 "다음"이 회색, 20자까지만 써진다. X → 제스처 탭
- [ ] 4-8 "다음" → 녹화(GS-04): "2 / 3", 막대 5칸, "0 / 5회", "녹화 중" 배지. 시연 "동작 한 번 녹화" 3번 → "3 / 5회", 파란 선, 일치도 86%
- [ ] 4-9 시연 "동작이 달라요"(GS-05): 주황 선과 48%, 주황 배너, "이번 동작 다시 하기"
- [ ] 4-10 시연 "겹침"(GS-06): "이미 있는 제스처와 너무 비슷해요", 파란·빨간 선, 유사도 88%, 빨간 배너, "다른 동작으로 다시 녹화"(0 / 5회부터), "취소"(제스처 탭)
- [ ] 4-11 5번을 채우면 분석 중(GS-14): 도는 고리, "분석 중 · N초"(숫자가 오름), 눌리지 않는 버튼 → 확인(GS-07): 칸 3개, "1 / 3회 · 성공 0회". "인식됨" → 초록 체크, "인식 안 됨" → 빨간 X
- [ ] 4-12 3번 중 2번 이상 → 완료(GS-08): "'이름'을 만들었어요", "앱에 연결하기"·"나중에 할게요". 2번 미만이면 확인을 다시 한다
- [ ] 4-13 "나중에 할게요" → 목록에 새 줄("쓰는 앱이 없어요"). "앱에 연결하기" → 앱 탭(AP-02에 새 줄이 "사용 안 함"으로 있다)
- [ ] 4-14 만드는 중 X·뒤로 가기·"취소"는 제스처 탭으로 돌아가고 제스처가 생기지 않는다
- [ ] 4-15 나만의 제스처 줄 → 상세(GS-11): 이름·만든 날, 인식률·되돌림, "쓰는 곳"(앱 줄 → 그 앱의 AP-02), "다시 녹화하기", "감도", 빨간 "제스처 삭제"
- [ ] 4-16 "감도" → 시트에서 "저장"하면 줄 값(둔감하게/보통/민감하게)이 바뀌고, 저장 없이 닫으면 그대로다
- [ ] 4-17 "다시 녹화하기" → 이름을 묻지 않고 녹화부터. 끝까지 하면 같은 줄의 인식률만 바뀐다
- [ ] 4-18 "제스처 삭제" → 확인 창(GS-12): 쓰는 곳에 따라 설명이 다르다(한 곳·여러 곳·없음). "취소"는 닫기만, "삭제"는 줄이 사라진다
- [ ] 4-19 나만의 제스처를 모두 지우면(GS-13) "아직 만든 제스처가 없어요", 설명, "제스처 만들기"(→ 이름 입력)
- [ ] 4-20 시연 "동기화 대기"를 켜고 상세를 열면(GS-15) 회색 배너, 주황 "동기화 대기" 배지, "· 이 폰에만 저장됨"

## 5. 발표 탭 (PR-01~17)

- [ ] 5-1 발표 탭: "PC 연결하기", "최근 연결한 PC" 2개, 설치 안내 배너. 시연 "최근 PC 비우기"면 "아직 연결한 PC가 없어요"와 설명(PR-17)
- [ ] 5-2 "PC 연결하기" → QR 화면 → 인식 영역 누르기 → "PC에 연결하는 중이에요"(PR-16: 고리, 정보 네 줄, "연결하는 중 · N초", "취소") → "강의실 PC와 연결됐어요"(PR-04). 여기서 뒤로 가면 발표 탭이다
- [ ] 5-3 최근 PC 줄로 연결하면 연결 중 제목에 PC 이름이 들어간다("강의실 PC에 연결하는 중이에요")
- [ ] 5-4 "코드로 입력할게요" → 숫자판(PR-03, 남은 시간이 줄어듦) → 6자리 → 연결. `000000`은 실패(PR-05) → "다시 스캔하기"·"코드로 입력"·X가 각각 동작한다
- [ ] 5-5 시연 "PC 응답 없게"를 켜면 연결 중 3초 뒤 실패(PR-05). 연결 중 "취소"·뒤로 가기 → QR 화면
- [ ] 5-6 PR-04 "다른 PC 연결" → QR 화면 → 연결 → 뒤로 가면 시작한 곳이다(QR 화면이 다시 나오지 않음)
- [ ] 5-7 "발표 준비하기" → 준비(PR-06): 연결된 PC, "발표 시간 10분", "끝나기 5분 전 진동", "미리 보낸 효과 2개 준비됨", 조작 방법 네 줄, "발표 시작". 뒤로 가면 PR-04다
- [ ] 5-8 "발표 시간" → 시트(PR-15, 5·10·15·20분, "저장"). 저장하면 바뀌고 저장 없이 닫으면 그대로다
- [ ] 5-9 "미리 보낸 효과" → 효과 관리(PR-14): 파일 세 줄(하나는 64% 보내는 중), "효과 추가" → 새 줄이 3초쯤 뒤 "보냄". 돌아가면 "3개 준비됨"
- [ ] 5-10 "발표 시작" → 발표 중(PR-07): 남은 시간이 고른 시간부터 줄어든다, 슬라이드 번호, 터치 영역 안내, 아래 도구 세 칸(그리기·화면 가리기·효과)
- [ ] 5-11 터치 영역을 누르고 있으면(PR-08) 파란 테두리와 손가락을 따라다니는 연한 파란 원, "포인터가 켜졌어요". 떼면 돌아온다
- [ ] 5-12 시연 "다음·이전 슬라이드" → 번호가 바뀐다. "5분 남음" → 시간이 주황, "5분 남았어요. 진동으로 알려 드렸어요."(진동을 끄고 시작했으면 "5분 남았어요."만)
- [ ] 5-13 시연 "연결 끊김"(PR-12) → 끊김 안내, 도구가 흐리고 눌리지 않음, 3초 뒤 복구
- [ ] 5-14 "그리기"(PR-09) → 타일이 파랗게, 안내 "누른 채 폰을 움직이면 그려져요". 누르고 있으면 펜 아이콘, "그리는 중이에요", "손을 떼고 3초 뒤 저절로 지워져요". 다시 누르면 꺼진다
- [ ] 5-15 "화면 가리기"(PR-10) → 파란 안내 "PC 화면을 검게 가렸어요…", 터치 안내 "누른 채 두 번 톡톡해도 돌아와요". 그리기와 동시에 켜지지 않는다. 시연 "누른 채 두 번 톡톡"으로도 켜고 끈다
- [ ] 5-16 위쪽 안내는 하나만 보인다(연결 끊김 > 5분 남음 > 화면 가리기)
- [ ] 5-17 "효과" 타일 → 효과 관리 → 뒤로 → 발표 중 그대로(시간·켜 둔 도구 유지)
- [ ] 5-18 발표 중 시스템 뒤로 가기는 먹지 않는다. "끝내기" → 요약(PR-13: 발표 시간·슬라이드 넘김·되돌림·오작동) → "확인"
- [ ] 5-19 "확인"은 흐름을 시작한 곳으로 간다: 홈에서 시작했으면 홈, 발표 탭이면 발표 탭, 기기 목록이면 기기 목록. 연결 실패의 X도 같다. 요약의 "기록 자세히 보기" → 기록

## 6. 설정·기록 (ST-01~08)

- [ ] 6-1 설정: 맨 위 로그인 줄(또는 계정 줄), "걷는 중엔 손 제스처 멈추기"·"주머니 제스처" 토글, 진동 "보통", 기록과 리포트, 기기, 권한, 배터리 설정 안내, 버전 0.3.0, 개발자 도구(디버그 빌드만)
- [ ] 6-2 토글은 나갔다 와도 유지된다
- [ ] 6-3 진동(ST-02): 슬라이더를 끌면 설정의 라벨이 "약하게/보통/강하게"로 바뀐다. "느껴 보기" 세 줄이 눌린다
- [ ] 6-4 기록(ST-03): 오늘·7일·30일 칩으로 숫자와 막대가 바뀐다. 성공률 막대 맨 아래 "원 그리기 88%"가 주황이다
- [ ] 6-5 7일 기록 맨 아래 "'원 그리기'를 자주 되돌렸어요 · 감도를 낮춰 볼까요?" → "조정" → 시트(ST-04) → 슬라이더를 왼쪽으로, "낮추기" → 카드가 사라지고 GS-11의 감도가 "둔감하게"다. "그대로 둘게요"는 바꾸지 않는다. 오늘·30일에는 이 카드가 없다
- [ ] 6-6 권한(ST-07): 알림·알림 접근·배터리 최적화 제외·카메라·전화 다섯 줄. 처음엔 "요청 전"(배터리는 "적용 안 됨"). 누르면 허용됨(초록) ↔ 허용 안 됨(빨강)으로 바뀐다. 알림 접근을 "허용 안 됨"으로 하면 앱 탭에 AP-05가 다시 나온다
- [ ] 6-7 배터리 줄과 설정의 "배터리 설정 안내" → ON-07. "설정 열기" → 닫히고 배터리가 "적용됨". 이미 적용된 채 열면 닫히지 않는다. "나중에 할게요"·뒤로는 닫기만 한다
- [ ] 6-8 개발자 도구(ST-08): 주황 "디버그 빌드에서만 보여요", 센서 여섯 칸 숫자가 계속 바뀜, 지연·배터리 세 줄, 판정 기준 네 줄(눌러도 아무 일 없음)
- [ ] 6-9 로그인하지 않았을 때 "로그인" 줄 → ON-10 → 로그인하면 설정으로 돌아오고 맨 위가 "허윤 / Google 계정으로 로그인됨"이다. "건너뛰기"·뒤로도 설정으로 돌아온다
- [ ] 6-10 계정 줄 → 계정(ST-05): 이름, "이 계정에 저장된 것"(나만의 제스처 1개·내 기기 3대·앱별 설정 2개 앱), "로그아웃". 줄을 누르면 제스처 탭·기기 목록·앱 탭으로 가고, 숫자는 목록을 따라 바뀐다
- [ ] 6-11 "로그아웃" → 설정으로 돌아오고 맨 위가 "로그인" 줄이다. 토글·앱 켜짐은 그대로다

## 7. 기기 (DV-01~09)

- [ ] 7-1 로그인 전 기기 목록(DV-01): "로그인하면 내 기기를 쓸 수 있어요" 줄(→ 로그인 → 기기 목록), "이번만 연결 2"(강의실 PC·윤의 MacBook), "기기 추가"
- [ ] 7-2 로그인 뒤: "내 기기 3"(윤의 MacBook 연결됨·거실 TV 꺼져 있어요·본가 TV 밖에서 조작 가능), "이번만 연결 1"(강의실 PC), "기기 추가"
- [ ] 7-3 "이번만 연결"의 PC 줄을 누르면 연결되고, 돌아오면 그 줄이 "연결됨 · 로컬 12ms"(파란 타일, 눌리지 않음)다
- [ ] 7-4 "기기 추가" → 시트(DV-02): QR 찍기·코드 입력·주변 기기 찾기. 어두운 곳·아래로 밀기·뒤로 가기로 닫힌다
- [ ] 7-5 "QR 찍기" → QR 화면 → 인식 영역 → 기기 목록 위에 "안방 TV를 어떻게 연결할까요?"(DV-03): "내 기기로 등록"(로그인 전이면 "로그인 필요" 배지)·"이번만 연결" 카드, 아래 큰 버튼. "코드 입력"으로 6자리를 넣어도 같다
- [ ] 7-6 카드를 바꾸면 버튼 글자가 바뀐다. "이번만 연결" → "이번만 연결"에 "안방 TV / 손님 · 같은 와이파이", 토스트 "안방 TV와 연결됐어요"
- [ ] 7-7 "내 기기로 등록": 로그인했으면 "내 기기"에 안방 TV가 늘고, 안 했으면 로그인 화면 → 로그인 뒤 같은 시트가 다시 뜬다
- [ ] 7-8 시연 "다음에 찍는 기기 바꾸기" 뒤 QR을 찍으면 시트 없이 바로 연결된다(지수네 TV → 스터디룸 PC → 다시 시트 순서)
- [ ] 7-9 내 기기 줄 → 상세(DV-04): 이름·종류, 허용 토글 셋(바로 저장), "연결된 사람 2"(나·민수 "끊기"), "조작 권한 되찾기", 기타 두 줄, 빨간 "내 기기에서 삭제". 연결된 사람이 없으면 "지금 연결된 사람이 없어요"
- [ ] 7-10 "민수 끊기" → 확인 창(DV-05) → "끊기"면 줄이 사라지고 "연결된 사람 1". "취소"·어두운 곳·뒤로는 닫기만 한다. "조작 권한 되찾기"는 나만 조작 중으로 만든다
- [ ] 7-11 "내 기기에서 삭제" → 확인 창 → "삭제" → 기기 목록에서 빠진다
- [ ] 7-12 "주변 기기 찾기" → DV-06: 도는 고리 "같은 와이파이에서 찾는 중", 1~2초 뒤 지수네 TV·스터디룸 PC, 회색 안내. 줄 → QR → 기기 목록에 손님으로 연결, 토스트
- [ ] 7-13 시연 "인터넷 끊기" 뒤 "기기 추가" → 인터넷 필요(DV-09): 구름 아이콘, 설명 세 줄, "다시 시도"(끊긴 동안은 그대로). 다시 연결하고 "다시 시도" → 기기 목록에 시트가 열린다
- [ ] 7-14 로그인한 채 홈의 조작 시트(HM-06)에 TV 줄이 있다(거실 TV 흐리게 "꺼져 있어요", 본가 TV "밖에서 조작 가능 · 서버 경유"). 로그인 전에는 TV 줄이 없다
- [ ] 7-15 "본가 TV" → 원격 조작(DV-08): "TV 화면에 '허윤 님이 조작 중'이 표시돼요.", "서버 경유"·"응답 180ms", 버튼 여섯 개, "조작 끝내기"(→ 홈, 조작 대상은 그대로)
- [ ] 7-16 "폰을 기기 쪽으로 향해서 고르기" → 레이더(DV-07): 회색 원 셋, 위쪽 파란 "거실 TV"와 부채꼴, "윤의 MacBook" 이름표, 안내 두 줄. 이름을 누르면 강조가 옮겨 가고, 강조된 것을 한 번 더 누르면 고른다. X → 홈
- [ ] 7-17 레이더에서 고르기: 꺼진 거실 TV → 토스트 "기기가 꺼져 있어 실행하지 못했어요". PC(연결 안 됨) → "연결된 PC가 없어 실행하지 못했어요". PC를 연결해 두면 조작 대상이 그 PC로 바뀌고 닫힌다
- [ ] 7-18 안방 TV를 내 기기로 등록한 뒤 레이더에 "안방 TV"가 생기고, 고르면 원격 조작이 "같은 와이파이"·"응답 12ms"로 열린다

## 8. 토스트 (SY-03, 홈 제목 길게 누르기)

- [ ] 8-1 여섯 가지(다음 곡으로 넘김·동작 되돌림·실행 실패·PC 연결됨·조작 대상 바뀜·되돌릴 동작 없음)가 하단 탭 바로 위에 뜬다. 실행 실패와 되돌릴 동작 없음은 아이콘이 없다
- [ ] 8-2 보통은 3초, "되돌리기"가 있는 것(조작 대상 바뀜)은 5초 뒤 사라진다. "되돌리기"를 누르면 바로 사라진다
- [ ] 8-3 떠 있는 동안 새 토스트를 띄우면 바로 바뀌고, 다른 탭으로 옮겨도 그대로 떠 있다가 사라진다

## 9. 실기기에서 손으로 볼 것

- [ ] 9-1 톱니·연습 카드·"PC 연결하기"를 빠르게 여러 번 눌러도 화면이 겹쳐 열리지 않는다
- [ ] 9-2 뒤로 가기: 홈에서는 앱 종료, 다른 탭에서는 홈, 하위 화면에서는 한 단계씩
- [ ] 9-3 상태바·아래 제스처 바에 글자와 버튼이 가리지 않는다. 긴 화면(설정·권한·개발자 도구·기기 목록)의 마지막 줄도 보인다
- [ ] 9-4 한글이 낱말 가운데서 갈라지지 않는다(예: QR 화면 안내 둘째 줄이 "나와요."로 시작)

- [ ] 9-6 글자 크기 200%: 버튼·칩·키패드가 글자만큼 커지고 본문이 스크롤된다. 발표 중 도구 세 칸의 높이가 같다. 칩 줄(발표 시간·기록·연습)은 옆으로 밀어 넘긴다. 끝나면 글자 크기를 되돌린다
- [ ] 9-7 자동 회전을 켜고 눕혀도 세로 그대로다. 다크 모드를 켜도 앱은 밝은 그대로다

- [ ] 9-9 TalkBack: 감지 카드가 "제스처 감지, 켜져 있어요, 스위치"로 한 번에 읽히고, 발표 터치 영역은 "누르고 있는 동안 제스처 인식", 불러오는 중 안내와 토스트는 뜰 때 저절로 읽힌다
- [ ] 9-10 작은 버튼("+ 만들기", "연결", "조정", 칩, 스위치, QR 화면 X)은 보이는 크기보다 조금 넓게 눌린다
- [ ] 9-11 안드로이드 14 이상에서 뒤로 가기 제스처를 천천히 끌면 이전 화면이 미리 보인다
- [ ] 9-12 반응이 바로 오고 스크롤이 부드럽다. 다른 앱에 갔다 와도 보던 화면이 그대로다
- [ ] 9-13 Figma와 나란히 볼 때 색·간격·글자가 같아 보인다. 같은 뜻의 결과 원은 같은 색이다(성공 초록·완료 파랑·실패 빨강·빈 화면 회색)

## 10. PC 에이전트 (PC-01~09, Windows·macOS)

Android Studio 위쪽 실행 목록에서 `pc-agent`를 고르고 ▶(처음엔 1분쯤 걸려요). 아직 가짜 값이라 폰과 이어지지 않아요. 왼쪽 메뉴를 **마우스 오른쪽 버튼**으로 누르면 시연용 동작이 나와요.

- [ ] 10-1 "MotionLayer" 창이 뜨고 왼쪽 메뉴 "폰 연결"(골라짐)·"발표"가 있다
- [ ] 10-2 폰 연결(PC-01): QR, "482 913", "0:42 뒤 바뀌어요"가 1초씩 줄고 0이 되면 코드와 QR이 바뀐다. "연결된 폰 없음" 배지, 스위치 두 개가 켜지고 꺼진다
- [ ] 10-3 시연 "폰 연결됨으로 바꾸기"(PC-02): "허윤의 Galaxy / 같은 와이파이 · 12ms · 이번만 연결", "연결됨", "끊기", 설정 세 줄. "끊기" → QR 화면
- [ ] 10-4 발표(PC-03): 포인터 크기 보통·색 파랑·그린 선 지우기 3초 뒤·미리 받은 효과 3개 · 40MB(줄은 눌리지 않음)
- [ ] 10-5 시연 오버레이(6초 뒤 사라짐): 포인터와 "허윤 조작 중" 이름표(PC-06), 파란 선과 "손을 떼면 3초 뒤 지워져요"(PC-07), 검은 화면과 "화면을 가렸어요…"(PC-08), 오른쪽 아래 효과 창 "시연 영상.mp4"(PC-09)
- [ ] 10-6 연결됨에서 "조작한 사람 이름 표시"를 끄면 오버레이에 이름표가 없다
- [ ] 10-7 시연 "움직이는 포인터 8초"·"그려지는 선"이 끊기지 않고 부드럽다. 선은 멈춘 뒤 3초 지나 사라진다
- [ ] 10-8 PowerPoint 슬라이드 쇼(전체 화면) 위에도 오버레이가 보인다
- [ ] 10-9 포인터 오버레이가 떠 있을 때 그 아래 창을 마우스로 누를 수 있는지 적어 둔다
- [ ] 10-10 창의 X를 누르면 창만 닫히고 트레이에 남는다
- [ ] 10-11 트레이(작업 표시줄 오른쪽 아래, 안 보이면 ∧)에 파란 아이콘이 있고, 오른쪽 버튼 메뉴(PC-04)가 "MotionLayer · 연결 대기"·QR 보기·설정 열기…·발표 오버레이 미리 보기·MotionLayer 종료다. 한글이 깨지지 않는다
- [ ] 10-12 "QR 보기" → 설정 창이 "폰 연결"로 열린다. "설정 열기…" → 열리거나 앞으로 나온다. "발표 오버레이 미리 보기" → 포인터와 이름표 6초
- [ ] 10-13 폰이 연결되면 Windows 알림(PC-05) "허윤의 Galaxy와 연결됐어요"가 뜨고, 트레이 메뉴 맨 위가 "MotionLayer · 연결됨"이다
- [ ] 10-14 "MotionLayer 종료" → 아이콘이 사라지고 프로그램이 끝난다

## 11. TV (TV-01~06, Android TV)

Android Studio 실행 목록에서 `tv-agent`, 기기를 TV 에뮬레이터로 고르고 ▶. TV 화면을 한 번 클릭한 뒤 방향키로 옮기고 Enter로 골라요. **M 키**로 시연용 동작 목록을 열고 닫아요.

- [ ] 11-1 처음(TV-01): "이 TV를 어떻게 쓸까요?", 개인 TV(파란 테두리)·공용 TV. 방향키로 테두리와 파란 아이콘이 옮겨 간다
- [ ] 11-2 확인 → QR 대기(TV-02): "폰으로 QR을 찍어 주세요", 순서 1·2·3, QR과 "482 913". 3번 글이 개인 TV는 "등록하거나 이번만 연결", 공용 TV는 "'이번만 연결'로 바로 써요"다
- [ ] 11-3 시연 "사람 둘 연결됨"(TV-03): "거실 TV" 아래 허윤(주인 · 지금 조작 중)·민수(손님 · 같은 와이파이), 맨 아래 "…주인의 폰에서 할 수 있어요."
- [ ] 11-4 공용 TV에서 시연 "손님 다섯 명": 민수·지수 두 줄과 "그 밖에 3명"(서연 · 도윤 · 하준), 맨 아래 "연결은 각자 폰에서 끊을 수 있어요." 화면 아래로 잘리지 않는다
- [ ] 11-5 시연 "모두 연결 끊기" → QR 화면, "처음 화면으로 되돌리기" → TV-01
- [ ] 11-6 시연 "조작한 사람"(TV-04): 오른쪽 위 "민수 ▸ 다음 채널"이 2초쯤 뒤 사라진다
- [ ] 11-7 시연 "원격 조작 중"(TV-05): 위 가운데 파란 띠 "허윤 님이 밖에서 조작하고 있어요"
- [ ] 11-8 시연 "효과"(TV-06): 오른쪽 아래 "지수가 보낸 사진", "3초 뒤 닫혀요"가 3 → 2 → 1로 줄고 닫힌다
- [ ] 11-9 시연 메뉴가 열린 채 뒤로 버튼을 누르면 메뉴만 닫힌다. 글자가 잘리거나 겹치는 곳이 없다
